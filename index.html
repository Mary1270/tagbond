Pay for a release. Prove it on GitHub.

A client escrows the reward and a publisher posts a bond. When the deadline arrives the contract reads the GitHub release itself: tag, publisher, publication time, asset name, size and, if you anchor one, the exact sha256 of the file. A matching hash pays out with no model opinion at all.

1AnchorRepository, tag, asset and optional sha256 are fixed on-chain before the bond is posted.
2ProveCode checks the release record. A hash match is proof; otherwise a model checks merit.
3SettleAutomated ruling, then an optional staked jury appeal. Payouts are pull-based.
